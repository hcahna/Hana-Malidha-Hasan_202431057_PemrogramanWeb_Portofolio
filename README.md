# Portfolio Pribadi - Tugas Web Design
Website portofolio pribadi ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web. Website ini menerapkan konsep Responsive Web Design (RWD) dan terdiri dari 3 halaman utama.

## Fitur
1. Responsive Design: Tampilan menyesuaikan perangkat (Desktop & Mobile).
2. Multi-page: Terdiri dari Home, Portfolio, dan Contact.
3. Form Validasi: Form kontak memiliki input text, select, textarea, dan checkbox.

## Teknologi yang Digunakan
- HTML5
- CSS3 (Flexbox)
